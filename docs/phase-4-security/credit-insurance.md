# P4-7 Credit insurance (D-79)

**[Product Manager + Compliance]** Documentation note only. Not built, not a launch blocker.

FSD Kenya 2015 (pp. 9, 12) discusses credit insurance as a way to share buyer default risk in invoice-discounting programmes. Mapema's approved default (Q-W / D-79, CEO sign-off 18 Nov 2026, Europe/London) is:

- Consider credit insurance **after the first live programme**, once a real loss history and a named insurer conversation exist.
- Do not hold go-live for a policy.
- Do not change pricing, the worked example, or concentration limits in anticipation of a policy.
- If a policy is later taken, it must sit behind an adapter (sandbox then live), with the insurer, the insured party (Mapema vs the buyer), waiting periods and exclusions documented for counsel and the CBK notice.

This note will be updated when an insurer is actually approached. No product code accompanies it.
